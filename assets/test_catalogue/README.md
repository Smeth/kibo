# Fixtures KIBO — kibo-demo-20261102-v1

108 annonces fictives, 12 par catégorie, 432 commentaires/réponses et une image
par annonce. Chaque titre et commentaire porte TEST ; les descriptions excluent
explicitement toute vente réelle. Prix XAF et villes du Congo-Brazzaville.

Images de catalogue pour essais provenant du jeu public DummyJSON :
https://dummyjson.com/docs/products

La source exacte, le produit source et le SHA-256 de chaque fichier figurent
dans catalogue.json. 108 fichiers, 95 contenus distincts ; certaines images
sont réutilisées comme illustrations, notamment pour services/formation/logement.
Les descriptions et échanges en français ont été rédigés pour ce jeu KIBO.
Il ne s’agit pas de photographies de biens proposés réellement par ces comptes.

Préparation : scripts/prepare_test_catalogue.py, depuis la réponse publique mise
en cache localement dans .dart_tool/demo-preparation/products.json. L’import et
les identifiants de comptes sont séparés ; aucun mot de passe ou jeton ici.

Ne pas rejouer automatiquement l’import à chaque lancement de KIBO.
